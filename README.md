# 9garn

ระบบรายรับ-รายจ่ายแบบหลายบ้าน

## สถานะเวอร์ชันนี้ (v2)

- รองรับ บ้าน 1 และ บ้าน 2 และสามารถเพิ่มบ้านผ่าน Sheet `Locations` โดยไม่ต้องแก้โค้ด
- ตารางและการคำนวณ (รายรับ/รายจ่าย/คงเหลือ) ของแต่ละบ้านแยกจากกันจริง — ตรวจสอบแล้วด้วยชุดทดสอบจำลอง ไม่มีการปนกันข้ามบ้าน
- ข้อมูลเก่าที่ไม่มีบ้านยังคงอยู่ในสถานะ `ยังไม่ระบุบ้าน` (ไม่ถูกลบ) และตอนนี้กรองดูเฉพาะกลุ่มนี้ได้จากเมนู "บ้าน" ด้วย
- รองรับการ normalize ชื่อ `บ้าน1`/`บ้าน 1` และ `บ้าน2`/`บ้าน 2` ทั้งตอนอ่านและตอนบันทึกใหม่
- datetime ถูกเก็บเป็น Plain Text รูปแบบ `yyyy-MM-ddTHH:mm:ss` เพื่อไม่ให้ timezone เลื่อน และอ่าน/แสดงผลตรงกันทั้ง Frontend, Apps Script, Google Sheets
- การคำนวณ balance แยกตามบ้าน + เดือน/วันที่ และไม่ขึ้นกับหมวดหมู่ที่เลือก
- Secret Token ไม่ถูกฝังไว้ใน Frontend แล้ว และ Backend ตรวจสอบชนิด/จำนวนเงิน/วันเวลา/ขนาดรูปภาพ

### ใหม่ใน v2

- เพิ่มฟังก์ชัน `migrateOldData()` ใน `Code.gs` — รันครั้งเดียวจาก Apps Script Editor
  เพื่อแปลงข้อมูลเก่าในชีต `Transactions` ให้เป็นมาตรฐานใหม่จริง (ไม่ใช่แค่ normalize ตอนอ่าน):
  - เขียน `location` กลับเป็นรูปแบบมาตรฐาน (`บ้าน 1` / `บ้าน 2`) หรือเว้นว่างไว้ถ้าระบุบ้านไม่ได้ (ไม่ลบแถว)
  - เขียน `datetime` กลับเป็น Plain Text แบบ Bangkok wall-clock time (กันไม่ให้ Sheets ตีความเป็น Date อีก)
  - ทำงานซ้ำได้ปลอดภัย (idempotent) ไม่มีการลบแถว/คอลัมน์ใด ๆ
- แก้ให้เมนูกรอง "บ้าน" ใน `index.html` แสดงตัวเลือก "ยังไม่ระบุบ้าน" เมื่อมีข้อมูลเก่าที่ยังไม่มีบ้านอยู่จริง
  (เดิมแสดงเป็นตารางแยกให้เห็นอยู่แล้ว แต่กรองเฉพาะกลุ่มนี้ผ่านเมนูไม่ได้)

## Google Sheets

`Transactions` ใช้โครงสร้าง:
`id | datetime | location | type | category | title | detail | amount | imageUrl`

`Categories` เก็บหมวดหมู่

`Locations` เก็บรายชื่อบ้าน/สถานที่ที่ระบบรองรับ โดยระบบสร้างให้เองหากยังไม่มี

## วิธี Deploy / อัปเดตจาก v1

1. เปิด Apps Script ของโปรเจกต์ (ผูกกับ Google Sheet เดิม, `SPREADSHEET_ID` เดิม) แล้ววาง `Code.gs` เวอร์ชันใหม่ทับของเดิม
2. รันฟังก์ชัน `migrateOldData()` หนึ่งครั้งจาก Apps Script Editor (เลือกฟังก์ชันจาก dropdown แล้วกด Run)
   เพื่อทำความสะอาดข้อมูลเก่าในชีต — ดูผลลัพธ์ได้จาก Logger (View > Logs)
3. Deploy > Manage deployments > แก้ไข deployment เดิม > New version เพื่อให้ Web App URL เดิมใช้โค้ดใหม่
   (ไม่ต้องสร้าง Deployment ใหม่ เพื่อให้ URL ที่ฝังใน `index.html`/`form.html` ยังใช้งานได้เหมือนเดิม)
4. อัปโหลด `index.html`, `form.html` เวอร์ชันใหม่ทับที่โฮสต์เดิม
